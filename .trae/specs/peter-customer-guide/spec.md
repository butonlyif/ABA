# Peter 说给家长听的使用说明（v3 · 真实功能版）

## Why
v2 家长反馈"内容太具体、又有标签，看不懂"。  
v3 重新来过 — **不再编造**。我们直接看产品里实际有什么、所有文案、按钮、字段，然后照着写一份**用户看得懂、走到每一步都对得上**的说明。

## What Changes
- 取消虚构的"志愿者 / 理疗师 / 陪伴师"三重身份卡
- 取消虚构的"5 步流程"
- 取消虚构的"3 条安心承诺"作为产品能力
- 改为按真实两个空间写：
  - **ABA 智能助手**（孩子）
  - **家长陪伴**（家长本人）
- 每段只写"我能看到什么 / 我可以做什么 / 结果是什么"
- 图表按 HTML 方式美化：流程图用 mermaid、信息层级用卡片

## Impact
- Affected specs: 无
- Affected code:
  - `.trae/specs/peter-customer-guide/家长使用说明.md`（重写）
  - `.trae/specs/peter-customer-guide/家长使用说明.html`（重写）

## ADDED Requirements

### Requirement: 入口与角色
注册/登录页必须先选要进入哪个空间：
- **ABA 智能助手**：孩子档案 · 评估 · 训练 · 进展
- **家长陪伴**：情绪支持 · 成长练习 · 反思日记

两个空间用同一账号 SSO 互跳，不需要重新登录。

### Requirement: ABA 智能助手 5 个 Tab
按真实 `mobile-web/src/main.tsx` 写：
1. **首页** — 问 AI（基于知识库 12 分册 326 文档块）/ 问专家（选专家 + 私信）
2. **孩子** — 多孩子切换、能力状态卡（按领域 %）、病例导入（PDF/Word/TXT/粘贴）、能力评估（39 题 "还不会/有时/经常"）、提交后自动生成训练任务
3. **训练** — 任务列表（按分类分组、排序、加新任务）、训练模板库（按领域浏览 + 搜索）、图片卡（127 类 6569 张）、训练试次（I/V/M/P/E 按钮 + 独立正确率 %）
4. **进展** — 训练天数、完成训练数、平均独立率、近期训练时间线、AI 训练报告（生成→PDF 下载）
5. **我的** — 切换到家长陪伴、退出登录

### Requirement: 家长陪伴 5 个 Tab
按真实 `mobile-web/src/main.tsx` 写 CoachApp：
1. **陪伴** — 情绪快捷选择 + 对话（基于 ACT 框架）
2. **情绪** — 多维记录（6 组情绪族 / 强度 1-5 / 触发场景 / 身体感受 / 应对方式）、本周趋势条、历史记录
3. **成长（ACT）** — 写下一个问题 → 6 步引导（觉察/接纳/解离/当下/价值/行动）→ 回到原问题记录结果；过往问题列表
4. **日记** — 每日反思 + 历史
5. **知识库** — 9 分类（育儿/自我关怀/情绪/关系/正念…）正文阅读

### Requirement: 详细步骤必须基于真实 UI
每一步必须能对应到真实页面元素：
- 评估页面有「还不会 / 有时 / 经常」3 选
- 训练试次有 I / V / M / P / E 5 个按钮
- 情绪记录有 6 组情绪族 + 强度 1-5
- ACT 是 6 步引导（觉察→接纳→解离→当下→价值→行动）
- 图片卡是 127 类 6569 张

### Requirement: 视觉与可读性
字号 17 / 标题 26、行距 1.85、米白 + 暖橙 + 柔绿。
移动端 720px 折单列、不溢出。

### Requirement: 输出双形态
- Markdown 同步更新
- HTML 单文件（CDN mermaid）
